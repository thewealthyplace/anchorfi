# AnchorFi Frontend

Landing page for the AnchorFi lending protocol. Built with Next.js 16 and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Deploy

The site is deployed on Vercel. Push to `main` triggers a redeploy automatically.

Manual deploy:

```bash
vercel --prod
```
